# Фикстура driver
## Фикстура определена в conftest.py, перед тестом: драйвер запускается, окно развёртывается, открывается нужная страница.
## После теста драйвер закрывается через driver.quit()

# data
## Хранятся данные для тестов

# 1. test_user_registration.py
## test_user_registration_registered - Успешная регистрация нового пользователя. Проверяется переход на главную и отображение аватара и имени.
## test_user_registration_wrong_mask_not_registered - Email не по маске. Проверяется, что поля выделены красным, появляется текст ошибки "Ошибка".
## test_user_registration_already_exist_not_registered - Регистрация уже существующего пользователя. Проверяется, что появляется ошибка валидации.

# 2. test_login_user.py
## test_login_user_logged_in - Успешный вход под зарегистрированным пользователем. Проверяется отображение аватара и имени "User".

# 3. test_logout_user.py
## test_logout_user_logged_out - После выхода аватар и имя исчезают, появляется кнопка "Вход и регистрация".

# 4. test_creating_advertisement.py
## test_creating_advertisement_unauthorized - Неавторизованный пользователь не может создать объявление. Появляется модальное окно с заголовком "Чтобы разместить объявление, авторизуйтесь".
## test_creating_advertisement_published - Авторизованный пользователь может создать объявление. Проверяется, что оно появилось в блоке "Мои объявления".
